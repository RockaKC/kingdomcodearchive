# sources-redirect

Keeps the old address, https://sources.kingdomcodearchive.com, working after the move to https://kingdomcodearchive.com.

Every file here is generated by `node tools/redirect_site.js` in [RockaKC/source-index](https://github.com/RockaKC/source-index) from the website's build at the time of the move. Each old page redirects to the same page on the new address (path, query and fragment kept) and names the new address as canonical; `404.html` does the same for any other address. Do not edit by hand.
